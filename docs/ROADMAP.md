## Stage One — archived and verified inside the dimensionless simulator

- [x] Historical carrier-only, fixed relay and adaptive-frontier algorithms.
- [x] Five seeds; 24 simulated drones; 240 steps per condition.
- [x] Frozen September 2026 evidence and historic comparison plots.
- [x] Reproducible Python execution and archived manifests.

## Stage Two — software engineering and research design

- [x] Three independent simulated Queen-led colonies, Relay/Retriever roles and midpoint eggs.
- [x] Scripted 3D visualization with six illustrative scenario timelines.
- [x] Finite docking reservations, non-creating repair energy, local Queen availability and synthetic sensor provenance.
- [x] Event-based abstract energy accounting with conservation assertions.
- [x] Configurable geometric radio radius and simple opaque-rectangle obstruction rejection.
- [x] Ten-seed fault smoke suite and exploratory C0–C6 engineering ablation (not unbiased policy comparison).
- [x] Successful 39-test CI on Python 3.10 and 3.12 for validated Stage Two run.
- [ ] Equalize hardware costs, specialist drones, starting energy and viable infrastructure across C0–C6.
- [ ] Model Retriever travel, module inventory, construction timelines, repairs and resupply.
- [ ] Add charging queue capacity, measurable battery states, dynamic RF throughput/interference and terrain-derived LoS.
- [ ] Generate ground-truth synthetic mapping tasks and measure *delivered/validated* sensor products.
- [ ] Use held-out paired terrain/fault seeds, confidence intervals and immutable full Stage Two evidence.
- [ ] Drive the React/Three.js frontend from **actual Python event traces**, not scripted placeholders.

## Stage Three — calibrated engineering and safety

- [ ] Validate component-level power (Wh, W), RF link budget, payload mass, endurance, and safe docking under hardware-in-loop tests.
- [ ] Evaluate per-colony authentication, command fencing under partitions, rescue authorization, and cybersecurity.
- [ ] Resolve institutional review, protected-site access and applicable aviation/spectrum compliance prior to any field operations.

**Publication sequence:** [Paper 1 draft](../papers/README.md) is available; Paper 2's midpoint egg benefit remains a hypothesis until a cost-matched comparative study is complete. Do not substitute visuals or passing unit tests for empirical flight safety.
