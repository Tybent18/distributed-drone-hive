# Research roadmap

[← Project home](../README.md) · [Methods](METHODS.md) · [Evidence](EVIDENCE.md) · [Safety](SAFETY.md)

## Stage One — implemented

- dimensionless 2-D energy-field simulation;
- carrier-only, fixed-relay, and adaptive-frontier policies;
- nominal and single-relay-failure scenarios;
- reproducible multi-seed evidence export;
- one-click desktop runner and deterministic demo;
- tests and Python 3.10/3.12 CI.

## Stage Two — computational research

- obstacle-aware radio propagation and line-of-sight loss;
- hive capacity, depletion, recharge, and contention;
- task allocation and communication bandwidth constraints;
- parameter sweeps, held-out seeds, and preregistered hypotheses;
- comparison with random, greedy, graph-centrality, and learned placement policies.

## Stage Three — validated engineering

- calibrated physics using published component specifications;
- hardware-in-the-loop tests with low-risk benchtop receivers;
- qualified safety, spectrum, security, and regulatory review;
- simulation-to-hardware transfer with explicit uncertainty bounds;
- controlled field trials only after institutional approval.
