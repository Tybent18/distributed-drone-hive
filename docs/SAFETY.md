# Safety and responsible-use boundary

[← Project home](../README.md) · [Methods](METHODS.md) · [Roadmap](ROADMAP.md)

This repository contains simulation software only. It does not provide RF emitter construction instructions, autonomous targeting, weaponization, surveillance identification, or unrestricted physical deployment control.

Any hardware program would require qualified engineering review covering spectrum authorization, electromagnetic exposure, thermal limits, battery safety, aviation rules, collision avoidance, cybersecurity, fail-safe recovery, environmental impact, and site-specific operating permission. Disaster-response or search applications must keep accountable human command and an auditable shutdown path.
